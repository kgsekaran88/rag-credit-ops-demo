# Meridian Credit Ops demo — LLM vs Unmanaged vs Managed RAG

Standalone teaching demo for **RAG in Practice** (Jerusalem College FDP).

## Quick start

```bash
python3 chat_app.py
```

Open **http://127.0.0.1:7860**
